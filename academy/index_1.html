4주 플랜혼자 완주하는 순서

하루 30분 기준입니다. 핵심은 강의를 다 듣는 게 아니라 매주 실제 업무 하나를 옮겨오는 것입니다. 안 옮기면 다음 주에 다 잊습니다.

1주차

Claude 101 · AI Capabilities and Limitations

먼저 도구를 손에 익힙니다. 그다음 AI가 왜 자신 있게 틀리는지를 배워두면, 결과물을 어디까지 믿을지 감이 잡힙니다. 이 감각이 없으면 나중에 크게 데입니다.

과제 — 이번 주 실제로 쓴 메일이나 보고서 하나를 Claude로 다시 써보고, 뭐가 다른지 비교해보기
2주차

Introduction to Claude Cowork

과제 — 매달 반복하는 정리 작업 하나를 골라 폴더째 맡겨보기
3주차

과제 — 2주차 작업을 스킬로 만들어 이름만 불러서 돌려보기

Claude Code 101 → (관심 있으면) Introduction to MCP

과제 — 작은 저장소 하나에 CLAUDE.md를 써보고, 규칙이 실제로 지켜지는지 확인

부록프롬프트가 잘 먹히는 네 겹

코스에서도 다루지만, 미리 알고 들으면 흡수율이 다릅니다. AI가 헤매는 건 대개 정보가 없어서가 아니라 판단 기준이 없어서입니다.

맥락 — 누가, 어떤 상황에서 읽는가

읽는 사람의 출발점과 소요 시간이 박히면 문장 난이도, 예시 개수, 생략할 것이 자동으로 결정됩니다.

흐릿함회의록 정리해줘
또렷함회의에 불참한 팀장이 3분 안에 파악할 수 있게 회의록을 정리해줘

재료 — 무엇을 근거로 삼을 것인가

"네가 아는 걸로 써줘"와 "첨부한 이 파일과 이 페이지만 근거로 써줘"는 결과가 다릅니다. 후자는 지어낼 여지를 막습니다.

흐릿함시장 동향 좀 정리해줘
또렷함첨부한 3개 보고서 안에 있는 수치만 써서 정리하고, 출처를 문장마다 표기해줘
